01

The Gap

r =0.12
Pearson correlation between correct defect identification and correct code fix, on the 7B baseline. Knowing what is broken barely predicts fixing it.

Can off-the-shelf GUI grounding supply the missing visual-to-code mapping, at zero retraining cost?

02

Method

  • OmniParser structural. YOLO bboxes, Florence-2 captions, EasyOCR text, pairwise geometric relations. Serialized as a text block in the prompt.
  • JEDI-7B click coords. Per-defect (x, y) click points injected as natural language: "click at 412, 87".
  • Prepend to Qwen2.5-VL repair prompt. Compare each grounded variant against the ungrounded baseline on the same 111 samples, paired stats.

06 · Code-perfect ≠ Visually-correct

On vanilla/sample_14, 7B scores CMLS 1.00, CMCS 1.00, IssAcc 1.00. The render is still wrong. The AST-level metrics only score edits overlapping the reference set; unmatched edits that break the layout go unpenalized.

Same pattern at scale. 72B + OmniParser on 68 alignment defects pooled across frameworks: CLIP +.007 (p < .01) rises while CMLS −.055 and CMCS −.045 (p < .05) drop on the same samples. Two metrics say better. Two say worse.

On generative UI repair, CLIP is the metric to trust.
07 · Which signal, when?
Framework7B72B
Angular OmniParserCLIP +.14 · CSR +18pp OmniParserCLIP +.01
Vanilla flat OmniParser / JEDICLIP +.02 · SSIM +.02
Vue OmniParserCLIP +.02 OmniParser / JEDICLIP +.01
React neutral JEDISSIM +.01 · MAE −1.2

Spatial defects > property defects in difficulty. Overflow and occlusion drive 38% of 7B compile failures; color/contrast is tractable at 27%. OmniParser encodes exactly what hard defects need: bboxes, relations, element text.

Takeaway
GUI grounding is free-lunch prompt scaffolding for VLM UI repair. It helps most where the model is weakest, and the right metric to trust is CLIP.
08 · Future work
  • Hybrid OmniParser + JEDI. OmniParser lifts visuals, JEDI lifts IssAcc and CMLS on 7B Angular. Combine them.
  • Diff-aware grounding. Ground only the broken-vs-target diff regions for a sharper signal.
  • Defect-conditioned prompts. OCR-heavy for text defects, relations-heavy for alignment.
